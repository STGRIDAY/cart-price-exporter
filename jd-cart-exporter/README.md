# 京东购物车价格导出（本地只读）

这是一个不联网、不收集账号信息的 Chrome/Edge 扩展。它仅从京东页面上已经渲染出来的文字中整理商品、价格和优惠信息，点击后下载 CSV 与 JSON 原始快照。

## 安装

1. 在 Chrome 或 Edge 打开 `chrome://extensions` 或 `edge://extensions`。
2. 打开右上角“开发者模式”，点击“加载已解压的扩展程序”。
3. 选择文件夹：`E:\PVOUT\jd-cart-exporter`。

## 使用

1. 自己登录京东；该工具不会处理登录、验证码、领券或下单。
2. 打开购物车，或勾选商品后进入“提交订单”页面。
3. 等优惠券、PLUS 优惠、京豆、红包、运费、白条支付优惠等完全刷新。
4. 点击右下角红色“导出可见价格与优惠”。

## 说明

- 最终应付金额以京东提交订单页为准，可能受收货地址、配送方式、已选优惠、支付方式和实时活动影响。
- CSV 将标价、到手价（最低可见价）、商品/店铺券、平台红包、跨店满减、PLUS/京豆、运费、其他优惠分列；JSON 保存同一时刻的原始文字，便于复核。
- 工具不会上传数据，也不会改变购物车内容。
