# 淘宝购物车价格导出（本地只读）

这是一个未联网、未收集账号信息的 Chrome/Edge 扩展。它仅在淘宝/天猫页面上读取**已渲染、可见**的文字，点击后下载：

- `淘宝价格导出_*.csv`：按“标价、到手价、商品/店铺券、平台红包、跨店满减、会员/淘金币、运费、其他优惠”分列，便于 Excel 打开和整理；
- `淘宝价格原始快照_*.json`：保留识别依据，方便核对。

## 安装

1. 在 Chrome 或 Edge 打开 `chrome://extensions` 或 `edge://extensions`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件夹：`E:\PVOUT\taobao-cart-exporter`。

## 使用

1. 自己登录淘宝；扩展不会处理登录、验证码、领券或下单。
2. 打开购物车，或勾选商品后进入确认订单/结算页。
3. 等页面价格、红包、优惠券和运费完全刷新；结算页通常最接近实际到手价。
4. 点击右下角橙色“导出可见价格与优惠”。下载的 CSV 用 Excel 打开即可。

## 注意

- “到手价”取该商品区域内的最低可见金额；最终金额仍受地址、运费、支付方式、红包勾选、会员权益与活动实时规则影响，应以提交订单前的页面合计为准。
- 由于淘宝页面结构和活动文案会更新，导出后请先核对“页面优惠/合计摘要”和“该商品页面文字”。
- 当前版本不会向任何服务器传送数据，也不会自动操作购物车。
